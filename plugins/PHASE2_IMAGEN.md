# 🖼️ Comandos de Imágenes - PHASE 2

**Categoría:** image  
**Requiere:** `sharp` (instalado ✅)

## Filtros Básicos
- `.grayscale` - Escala de grises
- `.blur` - Desenfoque
- `.sharpen` - Mayor nitidez
- `.invert` - Invertir colores
- `.sepia` - Efecto sepia
- `.resize` - 50% de tamaño
- `.compress` - Reducir tamaño archivo

## Ajustes de Luz/Color
- `.brighten` - Aumentar brillo
- `.darken` - Oscurecer
- `.saturate` - Más color
- `.desaturate` - Menos color
- `.hue` - Ajustar matiz
- `.contrast` - Mayor contraste

## Transformaciones
- `.rotate` - Girar 90°
- `.flip` - Voltear horizontal
- `.border` - Añadir marco
- `.round` - Esquinas redondeadas
- `.nocrop` - Cuadrado sin recorte

## Efectos Artísticos
- `.edge` - Detectar bordes
- `.posterize` - Efecto póster
- `.solarize` - Efecto solarizado
- `.pixelate` - Píxeles retro
- `.oil` - Efecto óleo
- `.manga` - Estilo manga
- `.vintage` - Retro/antiguo
- `.vignette` - Oscurecer bordes
- `.spread` - Dispersión
- `.heat` - Tonos cálidos
- `.cool` - Tonos fríos
- `.polaroid` - Foto Polaroid vintage
- `.sketch` - Boceto/lápiz
- `.glitch` - Efecto corrupto
- `.ascii` - Arte ASCII
- `.circle` - Formato circular
- `.mirror` - Efecto espejo
- `.extreme` - Filtro vibrant
