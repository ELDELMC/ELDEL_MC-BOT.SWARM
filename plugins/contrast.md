# 🎨 Comando CONTRAST

## Información General

**Comando:** `.contrast`
**Aliases:** `contraste`, `contrast-boost`
**Categoría:** Herramientas / Edición de Imágenes
**Descripción:** Ajustar contraste de imagen

**Estado:** ✅ Implementado

---

## 👥 Permisos Requeridos

| Rol | Puede Ejecutar |
|-----|---|
| **Usuarios Comunes** | ✅ Sí |
| **Administradores** | ✅ Sí |
| **Propietario** | ✅ Sí |

---

## 📋 Funcionalidad Técnica

Aumenta la diferencia entre áreas claras y oscuras de la imagen para mayor definición y nitidez visual.

---

## 🔧 Uso

### Sintaxis
```
Responder a imagen con:
.contrast
.contrast <nivel>     # 1-10
```

### Ejemplos
```
[Usuario responde a imagen]
.contrast              ← Contraste normal
.contrast 5            ← Contraste medio
.contrast 9            ← Contraste extremo
```

---

| Propiedad | Valor |
|-----------|-------|
| **Cooldown** | 3000ms |
| **Tiempo Proceso** | 2-5 segundos |
