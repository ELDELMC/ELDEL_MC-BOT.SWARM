# 📊 Comando PERCENTAGE

**Comando:** `.percentage` | **Aliases:** `porciento`, `percent`, `%`  
**Categoría:** Tools | **Todos pueden usar | Cooldown: 2s**

Calcula un porcentaje de un número.

## 🔧 Uso
- `.percentage 100 25` → Calcula el 25% de 100 (resultado: 25)
