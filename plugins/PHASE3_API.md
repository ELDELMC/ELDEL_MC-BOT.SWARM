# 🌐 Comandos con APIs - PHASE 3

**Requiere:** `axios` (instalado ✅)

## Información General
- `.weather [ciudad]` - Clima actual
- `.country [país]` - Datos de país
- `.ip [dirección]` - Información de IP
- `.exchange [cantidad] [de] [a]` - Conversión monedas
- `.status` - Estado de servicios

## Entretenimiento
- `.joke` - Chiste aleatorio
- `.meme` - Meme de Reddit
- `.fact` - Dato curioso
- `.advice` - Consejo aleatorio
- `.quote` - Frase motivacional

## Búsqueda/Información
- `.github [usuario]` - Perfil GitHub
- `.pokedex [pokemon]` - Info Pokémon
- `.wikipedia [término]` - Búsqueda Wikipedia
- `.lyrics [canción]` - Letras de canciones
- `.news` - Noticias tech
- `.book [título]` - Información de libros
- `.university [ciudad]` - Universidades
- `.movie [película]` - Info películas

## Imágenes/Fotos
- `.cat` - Foto gatito
- `.dog` - Foto perrito
- `.nasa` - Foto astronómica
- `.random-user` - Usuario fake generado

## Herramientas
- `.qrcode [URL]` - Genera código QR
- `.shortenurl [URL]` - Acorta URLs
- `.color [HEX]` - Info color hex
- `.translate [texto]` - Traductor (placeholder)
- `.oxford [palabra]` - Diccionario

## Criptomonedas
- `.crypto [moneda]` - Precio criptomonedas

## Otros
- `.anime [nombre]` - Info anime
- `.programming` - Chiste programadores
