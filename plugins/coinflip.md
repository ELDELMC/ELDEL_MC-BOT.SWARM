## 📋 Funcionalidad Técnica

### Descripción Detallada
El comando `.coinflip` simula el lanzamiento de una moneda, mostrando aleatoriamente "Cara" o "Cruz". Perfecto para tomar decisiones rápidas o resolver discrepancias.

### Cómo Funciona
1. Genera un número aleatorio (0 a 1)
2. Si > 0.5: Cara
3. Si ≤ 0.5: Cruz
4. Envía el resultado
