# 🔍 Comando INVERT

## Información General

**Comando:** `.invert`
**Aliases:** `negativo`, `invertir`, `inverse`
**Categoría:** Herramientas / Edición de Imágenes
**Descripción:** Invertir colores de imagen

**Estado:** ✅ Implementado

---

## 👥 Permisos Requeridos

| Rol | Puede Ejecutar |
|-----|---|
| **Usuarios Comunes** | ✅ Sí |
| **Administradores** | ✅ Sí |
| **Propietario** | ✅ Sí |

---

## 📋 Funcionalidad Técnica

Invierte todos los colores de la imagen al negativo fotográfico. Negro se vuelve blanco, rojo se vuelve cyan, etc.

---

## 🔧 Uso

### Sintaxis
```
Responder a imagen con:
.invert
```

### Ejemplos
```
[Usuario responde a imagen]
.invert                ← Invertir colores
```

---

| Propiedad | Valor |
|-----------|-------|
| **Cooldown** | 2000ms |
| **Tiempo Proceso** | 1-2 segundos |
