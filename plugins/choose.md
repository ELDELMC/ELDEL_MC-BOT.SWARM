# 📍 Comando CHOOSE

**Comando:** `.choose` | **Aliases:** `elegir`, `pick`, `seleccionar`  
**Categoría:** Tools | **Todos pueden usar | Cooldown: 2s**

Elige aleatoriamente entre múltiples opciones separadas por `|`.

## 🔧 Uso
- `.choose Pizza | Hamburguesa | Tacos` → Elige una opción
