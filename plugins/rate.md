# ⭐ Comando RATE

**Comando:** `.rate` | **Aliases:** `calificar`, `rating`  
**Categoría:** Fun | **Cooldown: 3s**

Califica a un usuario o cosa del 1-10 estrellas (aleatorio).

## 🔧 Uso
- `.rate @user` → Califica persona
- `.rate pizza` → Califica cosa
