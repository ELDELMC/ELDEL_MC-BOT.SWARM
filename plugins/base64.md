# 🔐 Comando BASE64

**Comando:** `.base64` | **Aliases:** `b64`, `encode`  
**Categoría:** Tools | **Todos pueden usar**

Codifica (encode) o decodifica (decode) texto en formato Base64.

## 🔧 Uso
- `.base64 encode Hola` → Codifica "Hola" en Base64
- `.base64 decode SGVsbG8=` → Decodifica el Base64
