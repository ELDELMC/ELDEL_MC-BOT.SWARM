# 🎲 Comando RANDOM

**Comando:** `.random` | **Aliases:** `rand`, `aleatorio`  
**Categoría:** Tools | **Todos pueden usar | Cooldown: 2s**

Genera un número aleatorio entre dos límites (default: 1-100).

## 🔧 Uso
- `.random` → Número entre 1 y 100
- `.random 50 100` → Número entre 50 y 100
