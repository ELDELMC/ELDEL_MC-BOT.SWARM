# 🖼️ Comando GRAYSCALE

## Información General

**Comando:** `.grayscale`
**Aliases:** `bw`, `blanco-negro`, `byn`
**Categoría:** Herramientas / Edición de Imágenes
**Descripción:** Convertir imagen a escala de grises

**Estado:** ✅ Implementado

---

## 👥 Permisos Requeridos

| Rol | Puede Ejecutar |
|-----|---|
| **Usuarios Comunes** | ✅ Sí |
| **Administradores** | ✅ Sí |
| **Propietario** | ✅ Sí |

---

## 📋 Funcionalidad Técnica

Convierte la imagen a escala de grises eliminando toda la información de color mientras mantiene el contraste y la luminosidad.

---

## 🔧 Uso

### Sintaxis
```
Responder a imagen con:
.grayscale
```

### Ejemplos
```
[Usuario responde a imagen]
.grayscale             ← Convierte a B&N
```
