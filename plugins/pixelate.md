# 🔲 Comando PIXELATE

## Información General

**Comando:** `.pixelate`
**Aliases:** `pixel`, `pixelizar`, `mosaic`
**Categoría:** Herramientas / Edición de Imágenes
**Descripción:** Pixelar imagen para efecto retro o privacidad

**Estado:** ✅ Implementado

---

## 👥 Permisos Requeridos

| Rol | Puede Ejecutar |
|-----|---|
| **Usuarios Comunes** | ✅ Sí |
| **Administradores** | ✅ Sí |
| **Propietario** | ✅ Sí |

---

## 📋 Funcionalidad Técnica

Aplica efecto pixelado/mosaico a la imagen para crear aspecto retro de videojuego o proteger privacidad.

---

## 🔧 Uso

### Sintaxis
```
Responder a imagen con:
.pixelate
.pixelate <tamaño>     # 1-20
```

### Ejemplos
```
[Usuario responde a imagen]
.pixelate              ← Pixelado normal (2x2)
.pixelate 5            ← 5x5 pixels
.pixelate 15           ← Muy pixelado
```
